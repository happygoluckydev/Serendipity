# Serendipity — 街歩きEC(仮) MVP

暇なときにぶらぶら歩きたくなる、「人が良かったと思ったもの」が並ぶ一枚の街。
[MVP設計書](https://claude.ai/artifact/VyvdGwFwPCggsMagVBWCwK) の「一枚の街を眺め、気になったものを保存し、自分でも置ける」までを実装しています。

- **眺める**: 重み付きボロノイ図(パワー図)で描いた一枚の街を、ズームとパンで歩く。引きでは街区の色、中ではマークの形と色、寄りではポップが読める。
- **気になる**: マークをタップするとポップ(一言・写真・経験の段階・PR表示)が開く。リンク先へは確認の一枚を挟む。
- **保存する**: ワンタップ、ログイン不要。保存時点のスナップショットを持つので、街から消えても手元に残る。
- **置く**: 座標ではなく「このマークの隣に置く」。名前の登録だけで置ける。
- **自分の店**: 保存から選んで公開すると、店そのものが「お店」のマークとして街に立つ。

## 構成

```
server/                         .NET 9 + HotChocolate(GraphQL) + EF Core + PostgreSQL
  src/Serendipity.Api/
    City/        街の中心: 置く・眺める・保存・店、種の配置(CityLayout)、重みと無常(Vitality)
    Safety/      許可リスト、PR(アフィリエイト)検出、プレビュー取得(SSRF対策つき)、AI判定、通報と運営
    Jobs/        バックグラウンド: 審査(5秒)、重み・消滅・配置のならし(5分)、リンク先の再チェック(1時間)
    GraphQL/     スキーマ(Query / Mutation)と表示用の型
    Identity/    端末ID(X-Device-Id)による利用者の識別
    Data/        DbContext、マイグレーション、許可リストの初期値と見本の街
  tests/         xUnit(単体 + 実 PostgreSQL を使う結合テスト)
web/                            React + TypeScript + Vite(モバイルファースト)
  src/geometry/  パワー図、街区の色、視点の計算(すべて単体テストあり)
  src/components/ 街ビュー、ポップ、置く、保存一覧、自分の店、せってい、運営画面
```

## 動かし方

必要なもの: .NET 9 SDK、Node.js 20 以上、PostgreSQL 14 以上。

```bash
# 1. API(初回起動でマイグレーションと許可リストの初期値が入る)
cd server/src/Serendipity.Api
dotnet run                     # http://localhost:5080
# 開発環境では見本の街(約40マーク)が入り、運営の鍵は dev-admin-key

# 2. クライアント(別のターミナル)
cd web
npm install
npm run dev                    # http://localhost:5173(/graphql などは API へ中継)
```

接続先は `ConnectionStrings__Default` で変えられます(既定は `Host=localhost;Database=serendipity;Username=postgres;Password=postgres`)。

本番相当では `npm run build` の結果が `server/src/Serendipity.Api/wwwroot` に出力され、API が同じオリジンで配ります。

### 主な設定(`appsettings.json` / 環境変数)

| キー | 意味 | 既定 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | あれば Claude で投稿を判定する。なければ簡易な語句判定 | なし |
| `Moderation__Model` | 判定に使うモデル(設計書の「軽量モデル中心」) | `claude-haiku-4-5` |
| `Admin__Key` | 運営画面(`/#admin`)と運営APIの鍵。空なら運営機能は無効 | 空 |
| `Seed__Demo` | 空の街に見本のマークを入れる | 開発環境のみ `true` |
| `Storage__Root` | 写真とプレビュー画像の保存先 | `data/files` |
| `City__*` / `Safety__*` | 重みの半減期・上限、消えるまでの日数、ポップの文字数など | 下の「暫定値」 |

## 設計書との対応

| 設計書の項目 | 実装 |
| --- | --- |
| 一枚の共有マップ / ズーム3段階 | `web/src/components/CityMap.tsx`。引き=街区の最多色(色の平均は使わない)、中=形と色、寄り=ポップ |
| マークを置く(隣に置く) | `CityService.PlaceMarkAsync`。隣は必須(空の街の最初の一つだけ例外)。隣接が正で、座標は `CityLayout` が導く |
| マークが重ならない | パワー図で平面を分割。置くときは誰とも重ならない位置を選び、周りをその場でならす |
| 反応による大きさと減衰・消滅 | `Vitality` と `MaintenanceService`。閲覧・タップ・保存・隣への配置を半減期つきで集計、上限あり |
| 新しいマークを控えめに光らせる | 置かれて3日以内の縁がゆっくり脈打つ(動きを減らす設定では止まる) |
| 使った/気になる/欲しいの区別 | 実線・破線・点線+斜線、ラベルと記号(◎ ？ ☆)でも示し、色だけに頼らない |
| 保存(ログイン不要)と引き継ぎ | 端末IDで保存し、名前を登録すると利用者へ移す。スナップショットに当時の隣も含む |
| 自分の店 | `ShopService`。保存は非公開、並べるのは明示操作。元の置き手とマークへ辿れる |
| 1画面チュートリアル | 初回だけ一つのマークが光り、触るとポップ、保存を一度だけ促して終わる。せっていから呼び戻せる |
| 誰でも使える条件 | 大きなタップ領域(小さい区画はまず寄る)、ズームボタン、文字の大きさ3段階、ホバー非依存 |
| 安全と審査 | 許可リスト、未知ドメインは本人のみ可視→運営確認、AI判定、プレビューの自サーバー保存、定期再チェック、PR自動検出、信頼度、重み付き通報と自動非表示、ブラックリスト、外部遷移の確認、削除依頼窓口 |
| 子ども | 子ども向けにすると外部リンクを渡さない(API側で `linkUrl` を返さない) |

## 未決事項への暫定値

設計書の「未決事項」は、MVP を動かすために次の値で仮置きしています。どれも設定か1か所の定数で変えられます。

- **ジャンルの色(8色)**: ファッション / 暮らし・雑貨 / 食 / 本・学び / 趣味・遊び / テック・道具 / 美容・健康 / 場所・体験(`web/src/domain.tsx`、`Domain/Enums.cs`)
- **ポップの文字数**: 60文字(絵文字などは1文字と数える)
- **何の隣でもなく置く**: 街が空のときの最初の一つだけ許す
- **重みの式**: `1 + Σ 種別の重み × 0.5^(経過日数/3日)`、上限6。閲覧0.1・タップ0.5・保存2・隣への配置3
- **減衰と消滅**: 反応のない日が21日を過ぎると薄れ始め、45日で街から消える(閲覧だけでは延命しない)
- **子ども向けへの切り替え**: 端末ごとの設定(登録済みなら利用者にも反映)
- **「お店」マークと「自分の店」**: 形の名前は「お店」、機能は「自分の店」と呼び分け
- **画像のAI判定**: 未実装(文章・リンク先タイトル・本文はAIで判定)
- **信頼度**: 新規は1日5個まで。登録7日以上・公開3個以上・非表示なしで「通常」(1日20個)に自動で上がる

## MVP として割り切っていること

- 端末IDがそのまま資格情報です(DBにはハッシュのみ保存)。別の端末からのログインはありません。
- 画像はローカルディスクに保存しています(`IObjectStorage` を差し替えればオブジェクトストレージにできます)。
- 運営は共有の鍵1本で操作します。
- 子ども向けの切り替えには保護者の確認がありません。
- 年齢規制とリンク先の責任範囲は、公開前に専門家の確認が必要です(設計書のとおり)。
